📝 ใบงานปฏิสัมพันธ์: Association Rules

วิชา Data Mining

เรียนรู้และประเมินผลผ่านสถานการณ์จริง

กฎความสัมพันธ์ (Association Rules) เป็นโมเดลการเรียนรู้แบบไม่มีผู้สอนเพื่อหาความเชื่อมโยงระหว่างสินค้า ให้นักเรียนศึกษาทฤษฎีอ้างอิงและตารางข้อมูลธุรกรรมด้านล่างนี้ จากนั้นกรอกข้อมูลในช่องว่างเพื่อทำการส่งตรวจคะแนนแบบเรียลไทม์

1. Support (ความนิยม)

อัตราการเกิดขึ้นของกลุ่มสินค้าเทียบกับประวัติธุรกรรมทั้งหมด

Support(A → B) = P(A ∪ B)

2. Confidence (ความน่าเชื่อถือ)

ความน่าจะเป็นที่จะพบบสินค้า B ในบิลเมื่อระบุว่ามีสินค้า A อยู่แล้ว

Confidence(A → B) = P(B | A)

3. Lift (ความเข้มแข็งของกฎ)

ดัชนีชี้วัดว่าการซื้อ A มีแรงผลักดันต่อการร่วมซื้อ B มากกว่าปกติเพียงใด

Lift(A → B) = Confidence / Support(B)

Algorithm Choice Lab

เลือกใช้อัลกอริทึมให้เหมาะกับงาน Association Rules

ฝึกแยกความต่างระหว่าง Apriori Algorithm และ FP-Growth จากคุณลักษณะของข้อมูลจริง เพื่อให้เลือกวิธีค้นหา frequent itemsets ได้ถูกต้อง

แนวคิดหลัก
Apriori สร้าง candidate หลายรอบ ส่วน FP-Growth บีบอัดข้อมูลเป็น FP-tree เพื่อลดการสแกนซ้ำ

Apriori Algorithm

  • เหมาะกับ dataset ขนาดเล็กถึงกลาง หรือใช้สอนเพื่อเห็นขั้นตอน candidate generation ชัดเจน
  • ใช้หลัก frequent itemset: ถ้า itemset ใหญ่ frequent แล้ว subset ของมันต้อง frequent ด้วย
  • ข้อจำกัดคืออาจสร้าง candidate จำนวนมากและต้องสแกนฐานข้อมูลหลายรอบ

FP-Growth

  • เหมาะกับ dataset ใหญ่หรือข้อมูลแน่นที่มี item ซ้ำจำนวนมาก
  • สร้าง FP-tree เพื่อบีบอัดธุรกรรม แล้วหา frequent patterns โดยไม่สร้าง candidate ทุกชุด
  • ข้อจำกัดคือเข้าใจโครงสร้าง tree ยากกว่า และต้องจัดการหน่วยความจำของ tree
